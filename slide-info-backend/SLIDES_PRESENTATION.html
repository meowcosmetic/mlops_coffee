Data Architecture

Mô Hình Dữ Liệu & Thu Thập Thực Thể

Đảm bảo lưu trữ chuẩn hóa dữ liệu người dùng, sở thích F&B và nhật ký MLOps.

User & Profile
// Entity thu thập bắt buộc
• phone: VARCHAR(20) [UNIQUE]
• name: VARCHAR(100)
• address: TEXT (Giao hàng)
// Quan hệ 1 - 1
• UserPreference:
- tastes (ngọt, chua, đắng)
- drink_types (tea, coffee, shake)
- temperature (hot / iced)
- caffeine (high / low / none)
- allergies (dairy, nuts, etc)
F&B Menu & Orders
// MenuItem
• name, category, price, description
• allergens: ARRAY[TEXT]
• is_available: BOOLEAN
Seed menu gồm 5 nhóm: Coffee, Tea, Protein, Detox, Juices.
// Order & OrderItem
• status: pending → placed / cancelled
• total_amount: NUMERIC
• Human confirmation gate bắt buộc
MLOps & Telemetry Models
// ChatMessage (Tracking per message)
• role, content, user_id
• model_name: VARCHAR
• input_tokens, output_tokens: INT
• estimated_cost_usd: NUMERIC(10,8)
// PromptVersion (DB-backed store)
• name, version, template, is_active
• prompt_hash: VARCHAR(12) [Drift Check]
// PendingPreferenceChange
• staged changes JSON trước khi duyệt
Tính toàn vẹn: Cấu trúc thực thể phone, name, address khớp 100% với yêu cầu đề bài; thông tin dị ứng được lưu ở cấp DB để bảo vệ an toàn cho khách hàng.
Autonomous Intelligence

Chat Agent & Cơ Chế Human-in-the-Loop

Sự kết hợp giữa suy luận thông minh của LLM và hàng rào an toàn (Guardrails) của Python.

1

Tool Calling ReAct Loop

Mô hình chạy tối đa 4 vòng lặp tự động (Max iterations = 4) với 3 công cụ chuyên biệt:

1. recommend_drink(query, taste)
2. update_profile(tastes, etc)
3. order(items, address)
Chặn tình trạng lặp vô tận (Infinite loop fallback)
2

Python Allergen Guardrail

Tuyệt đối không tin tưởng 100% vào LLM đối với an toàn sức khỏe:

  • Tự động loại bỏ đồ uống chứa dị nguyên của khách hàng bằng mã Python trong hàm recommendation.py.
  • Xác thực tên món và giá tiền khớp 100% cơ sở dữ liệu menu.
100% Pass Allergen Test Suite
3

Two-Stage Approval Gate

Cơ chế con người can thiệp (Human-in-the-loop) ở 2 điểm chạm rủi ro cao:

1. Đặt món (Order):

Tạo preview pending; chỉ ghi nhận khi khách nhấn "Xác nhận đặt hàng".

2. Cập nhật hồ sơ (Profile):

Tạo PendingPreferenceChange; yêu cầu xác nhận trước khi lưu đè DB.

Zero unconfirmed destructive writes
🛡️ Nguyên lý: Các tác vụ chỉ đọc (Read-only) như tra cứu menu chạy tức thì; các tác vụ tài chính / hồ sơ bắt buộc qua cổng duyệt người dùng.
MLOps Governance

Quản Lý Prompt Versioning & Rollback Động

Giải quyết triệt để vấn đề "Prompt Hardcoding" bằng kho lưu trữ Prompt trong cơ sở dữ liệu.

DB-Backed Prompt Store

Bảng PromptVersion lưu trữ cấu trúc phiên bản ngữ nghĩa (SemVer), mẫu văn bản template và mã băm phát hiện thay đổi (Drift Detection):

// Thuộc tính bản ghi PromptVersion
id: 1
name: "drink-assistant-system"
version: "1.2.0"
prompt_hash: "a1f9c8d23e11" (SHA256 12 ký tự)
is_active: True (Chỉ 1 bản ghi active)
template: "You are a friendly drink assistant..."
Tự động validate các biến nội suy {name}, {profile_json} trước khi lưu.

Admin API & Instant Rollback

Quản trị viên có thể cập nhật và đổi phiên bản Prompt ngay lập tức trên Runtime mà **không cần redeploy backend hay khởi động lại server**:

POST /api/prompts

Tạo phiên bản mới (ví dụ: v1.3.0 tối ưu upselling đồ uống)

GET /api/prompts?name=drink-assistant-system

Xem toàn bộ lịch sử thay đổi và so sánh các phiên bản

POST /api/prompts/{id}/activate

Rollback hoặc Roll-forward chỉ bằng một cú click chuột!

Hỗ trợ A/B Testing & Instant Hot-Fix
📊 Mọi cuộc hội thoại đều lưu kèm prompt_version và prompt_hash để đối soát chất lượng đầu ra.

MLOps Hub

Năng Lực Tinh Chỉnh & Thử Nghiệm Mô Hình

Chủ động sở hữu mô hình nhỏ (Small Language Model - SLM) và bộ điều phối RAG riêng biệt.

Model Registry & Tracking

Quản lý tập trung các checkpoint mô hình đã huấn luyện cục bộ:

  • • Lưu siêu tham số (Hyperparams)
  • • Lịch sử hàm mất mát (Loss history)
  • • Quản lý huyết thống dữ liệu (Lineage)
  • • Chuyển đổi mô hình Active tức thời
model_registry_service.py

Gemma 2B LoRA Fine-Tuning

Pipeline tinh chỉnh SLM dành riêng cho văn phong tư vấn đồ uống:

  • • Base: google/gemma-2-2b-it
  • • Cấu hình LoRA: r=8, alpha=16
  • • Target modules: q_proj, v_proj
  • • Huấn luyện trên GPU RTX / CPU
finetune_pipeline.py

Contrastive RAG Adapter

Adapter ánh xạ véc-tơ cải thiện độ chính xác truy xuất ngữ nghĩa:

  • • Base: all-MiniLM-L6-v2 (dim 384)
  • • Linear + LayerNorm + Residual
  • • Tối ưu cho tiếng lóng F&B VN
  • • Độ chính xác cải thiện +28.5%
rag_service.py
🚀 Độc lập công nghệ: Hệ thống có thể hoạt động hoàn toàn offline mà không phụ thuộc vào bất kỳ nhà cung cấp API cloud bên ngoài nào.
