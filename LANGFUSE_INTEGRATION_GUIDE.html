Langfuse Là Gì & Được Ứng Dụng Ra Sao Trong DrinkBot MLOps?

Langfuse là chuẩn công nghiệp về LLM Observability. Trong đồ án này, chúng ta triển khai theo kiến trúc 100% Chạy Local & Tự Trị (Self-Contained In-Memory Telemetry): Tất cả số liệu token, độ trễ ms, chi phí USD và chuỗi gọi Tools được hệ thống nội bộ ghi nhận và hiển thị ngay trên Sidebar Dashboard tích hợp trong giao diện Chat mà không cần mở tài khoản hay gửi dữ liệu ra bất kỳ dịch vụ bên thứ ba nào!

🏠

Tại sao hiển thị Log trực tiếp trên Sidebar mà không cần Langfuse Cloud?

• Chạy hoàn toàn Local (Offline-Ready): Trực quan hóa dữ liệu qua Sidebar giúp sinh viên, giảng viên và tester có thể quan sát hành vi của AI, lượng token tiêu thụ và các tool call ngay khi đang chat trên máy tính mà không cần Internet.
• Khi nào cần mở Langfuse Cloud? Trong môi trường doanh nghiệp quy mô lớn với hàng nghìn người dùng, bạn có thể điền Public/Secret Key từ Langfuse Cloud vào file .env để đồng bộ dữ liệu tập trung lên web server của họ. Còn đối với đồ án và kiểm thử, toàn bộ đã được gói gọn hoàn chỉnh trong ứng dụng local của bạn!

🏛️ 4 Cột Trụ Cốt Lõi Langfuse Mang Lại Cho Dự Án

🔍

1. Nested Tracing

Quan sát toàn bộ chuỗi mắt xích lồng nhau: từ câu hỏi người dùng → Agent suy nghĩ → Tool recommend_drink lọc SQL → trả lời khách.

💰

2. Token & Cost Tracking

Tự động bóc tách Prompt Tokens, Completion Tokens và tính toán chi phí USD tức thì theo giá model (ag/gemini-3.8-flash-low).

⏱️

3. Latency Profiling

Đo đạc chính xác thời gian thực thi (Latency ms) của từng vòng lặp LLM invocation để phát hiện các bottleneck hoặc trường hợp loop quá lâu.

🏷️

4. Version & Metadata

Gắn nhãn phiên bản Prompt, ID người dùng và trạng thái gọi Tool, giúp đối chiếu chất lượng giữa các phiên bản Prompt mà không lo mất dấu.

2. Agent Turn Hook: app/services/agent.py Agent Loop

Đo đạc độ trễ, lưu vết đầy đủ câu hỏi, phản hồi AI và toàn bộ tham số + kết quả của Tool Calling: 

# Khởi tạo trace_id và danh sách tool execution
turn_start_time = time.perf_counter()
trace_id = f"trace-{uuid.uuid4().hex[:12]}"
tools_called_list = []
tool_calls_detail = []

# Vòng lặp tool calling
for call in tool_calls:
    tools_called_list.append(call.get("name"))
    result, extra = await _dispatch(db, user, prefs, call)
    # Lưu đầy đủ arguments từ LLM và kết quả thực thi của backend:
    tool_calls_detail.append({
        "tool": call.get("name"),
        "args": call.get("args"),
        "result": result
    })

# Kết thúc turn: ghi nhận đầy đủ prompt, full response & tool calls detail
langfuse_service.record_trace(
    trace_id=trace_id,
    input_text=message,       # Không cắt ngắn
    output_text=reply,        # Toàn bộ phản hồi của AI
    tools_called=tools_called_list,
    tool_calls_detail=tool_calls_detail,
    ...
)
3. API Endpoint: app/routers/telemetry.py FastAPI

Cung cấp REST endpoint cấp dữ liệu Trace, Full Response & Tool Execution cho Sidebar: 

@router.get("/telemetry/traces")
async def get_traces(limit: int = 30):
    return {
        "langfuse_enabled": True,
        "traces": langfuse_service.get_recent_traces(limit)
    }

@router.post("/telemetry/traces/clear")
async def clear_traces():
    langfuse_service.clear_traces()
    return {"status": "cleared"}

🚀 Cách Kiểm Tra Tính Năng Trực Tiếp Trên Trình Duyệt

  1. Mở ứng dụng chat tại: http://localhost:3000.
  2. Đăng nhập vào tài khoản của bạn (hoặc tạo tài khoản mới).
  3. Ở góc trên thanh Header, bạn sẽ thấy nút: ⚡ Langfuse Traces.
  4. Gửi một tin nhắn bất kỳ (Ví dụ: "Gợi ý cho mình món cà phê nào ít đường không sữa với").
  5. Bấm vào nút ⚡ Langfuse Traces: Sidebar sẽ trượt ra từ bên phải màn hình, hiển thị đầy đủ:
    • Trace ID độc nhất cho lượt chat.
    • Thời gian phản hồi (Latency) chính xác tính bằng millisecond.
    • Số lượng Token (Input Tokens và Output Tokens).
    • Chi phí USD quy đổi.
    • Danh sách Tool đã gọi (update_profile, recommend_drink, order).
    • Click vào từng card trace để bung xem câu trả lời chi tiết và Model name!
